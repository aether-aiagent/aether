# Aether promo copy (EN)

## One-liner

Aether is an on-device AI agent for Android: it runs bash, edits files, keeps a local
Alpine runtime, connects MCP servers and subagents, and works with any model — while your
data never leaves the phone.

## Paragraph

Aether is not a cloud chatbot. It ships a local runtime (Alpine proot or Termux), executes
shell commands, applies precise file edits, searches file contents, installs packages and
loads extensions with MCP servers. Point it at any OpenAI-compatible endpoint, Anthropic,
Gemini or a local Ollama instance. History, files and provider keys stay on the device;
the only outbound traffic is your own request to the model you chose. APKs are signed with
a single key, so updates install over the previous version without losing chats.

## Feature bullets

- Local runtime: Alpine proot + Termux, bash, package installs
- Tools: bash, read, write, edit, grep, find, ls plus extension tools
- Any model: OpenAI-compatible, Anthropic, Gemini, local Ollama
- MCP servers and background subagents
- Shizuku / Agent Mode: device control without root
- Markdown with callouts, charts and interactive polls in chat
- Text-to-speech for replies, code copy, full-text chat search
- Chat folders, archive and swipe actions; configurable haptics and typing styles
- Self-update from GitHub Releases, installs over the old version
- Debian 13: Aether Desktop, an Electron GUI app

## Post for X / Reddit / Hacker News

**Aether — an AI agent that lives on your Android phone, not in someone's cloud.**

It keeps a local Alpine runtime, runs bash, edits files with exact-match patches, greps
your storage, installs packages and speaks MCP. Bring your own model: any
OpenAI-compatible endpoint, Anthropic, Gemini or local Ollama. Everything else — history,
files, keys — stays on the device.

The UI does streaming markdown with callouts, charts and polls, TTS for replies, chat
folders and an archive, an animated bot avatar and tunable haptics. Signed with one key,
so updates install over the top and keep your chats.
