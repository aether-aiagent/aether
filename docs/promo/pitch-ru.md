# Промо-тексты Aether (RU)

Готовые формулировки для постов. Бери целиком или собирай из блоков.

## Питч в одно предложение

Aether — AI-агент, который живёт на Android: читает и правит файлы, запускает команды в
локальной Alpine-среде, подключает MCP-серверы и суб-агентов, работает с любой моделью и
не отправляет ничего на чужие серверы.

## Питч в абзац

Aether — это не чат-бот в облаке, а агент на устройстве. Он держит локальную среду
(Alpine proot или Termux), выполняет bash-команды, правит файлы точечными правками, ищет
по содержимому, ставит пакеты и подключает расширения с MCP-серверами. Интерфейс и
настройки — на русском. История, файлы и ключи провайдеров остаются на телефоне: наружу
уходят только ваши запросы к выбранной модели. APK подписан одним ключом, обновления
ставятся поверх без потери данных.

## Короткий список фич для поста

- Локальная среда: Alpine proot + Termux, bash, установка пакетов
- Инструменты: bash, read, write, edit, grep, find, ls + инструменты расширений
- Любая модель: OpenAI-совместимый API, Anthropic, Gemini, локальная Ollama
- MCP-серверы и фоновые суб-агенты
- Shizuku / Agent Mode: управление устройством без root
- Markdown с колаутами, графиками и опросами прямо в чате
- Озвучка ответов, копирование кода, поиск по всем чатам
- Папки, архив и свайпы в списке чатов; вибрация и стили печати настраиваются
- Автообновление из релизов репозитория, установка поверх
- Debian 13: отдельное GUI-приложение Aether Desktop (Electron)

## Ответы на частые вопросы поста

**Нужен ли root?** Нет. Root или Shizuku нужны только для операций с другими
приложениями (Agent Mode). База работает в изолированной Alpine-среде.

**Куда уходят мои данные?** Никуда, кроме выбранного вами провайдера модели. Серверов у
проекта нет.

**Это бесплатно?** Да, GPL-3.0. Платите только своему провайдеру модели, если он платный.

**Почему APK, а не Play Store?** Релизы идут напрямую из GitHub Releases; подпись одним
ключом гарантирует установку поверх и автообновление из приложения.
