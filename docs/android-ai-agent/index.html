Android AI agent

Aether is an open-source AI agent for Android. The model does not just answer — it runs bash, reads and edits files, greps a project, calls MCP servers and works inside a local Alpine runtime. Everything stays on the phone except the model request itself.

Скачать APK Исходники на GitHub

What it does

  • LLM chat with any OpenAI-compatible provider
  • Tools: bash, read, write, edit, grep, find, ls with approval for destructive calls
  • Local Alpine (proot) runtime, optional Termux integration
  • MCP servers, subagents, extensions and reusable skills
  • Kotlin + Jetpack Compose, Material 3 UI, Russian and English

Install

Download Aether-v2.4.1.apk from Releases. Android 8.0+. Updates install on top of the previous version and keep your chats.
