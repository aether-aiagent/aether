Termux AI agent

If you already live in Termux, Aether can use it as its runtime: the agent runs commands in your Termux environment instead of the bundled Alpine image, so your packages, dotfiles and scripts are right there.

Скачать APK Исходники на GitHub

How it works

  • Settings → Runtime → Termux switches the agent's shell to Termux
  • The agent sees the same files you see in Termux
  • Workspace switching keeps Alpine and Termux independent

What the agent can do there

Run builds, install packages, grep and patch repositories, drive git, start MCP servers — with each call shown and destructive ones gated behind approval.

Get it

Signed APK in Releases, Android 8.0+. Termux is optional; Aether works standalone.
