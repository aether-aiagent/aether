Local LLM on Android, with tools

Aether connects to any OpenAI-compatible endpoint, including a model served on the phone itself or on your own machine over the network. What makes it an agent: the model gets a real tool loop — shell, files, search, MCP servers — and a local Alpine environment to run in.

Why an agent and not a chat app

A chat window gives you text. Aether gives the model hands: it lists directories, greps code, patches files and runs commands, showing each step with arguments and output.

Setup

  • Settings → Providers: base URL, API key, model id
  • Any endpoint that speaks OpenAI chat-completions works
  • Settings → Runtime: bundled Alpine (proot) or Termux

Privacy

Chats, files and the runtime live on the device. Only the model request leaves the phone, to the provider you configured.
