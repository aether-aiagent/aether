# Спонсоры: где искать и что писать

## Что работает, а что нет

GitHub Sponsors требует выплат через Stripe, а для России это недоступно — заявку можно
подать, но выплаты не пройдут. Поэтому схема такая: кнопка **Sponsor** в репозитории через
`custom:`-ссылки на Boosty / DonationAlerts / ЮMoney, а GitHub Sponsors включаем позже,
если появится зарубежный получатель выплат.

## Три типа спонсоров

**1. Частные подписчики.** Дают 100–500 ₽/мес, приходят из контента: посты про локальные
модели, разборы «как я сделал агента на телефоне», видео. Конверсия появляется только когда
человек уже пользуется приложением — сначала рост скачиваний, потом кнопка доната.

**2. Разработчики и небольшие команды.** Дают разово 1–5 тыс. ₽ за конкретную фичу или
интеграцию. Ищутся там, где люди жалуются на отсутствие нормального агента под Android:
issues в похожих проектах, r/androidapps, r/LocalLLaMA, Telegram-чаты про Termux и локальные модели.

**3. Компании.** Дают 10–50 тыс. ₽/мес за размещение логотипа и упоминание. Кому это надо:
провайдеры API моделей (им нужен клиент под Android), хостинги GPU, VPN, сервисы логирования
LLM. Писать напрямую в dev-rel: короткое письмо, метрики установок, скриншоты, цена.

## Что писать в письме (шаблон)

```
Тема: Aether — открытый ИИ-агент для Android, 1 экран и предложение

Здравствуйте! Я делаю Aether — open-source агент для Android: чат с любой
OpenAI-совместимой моделью, инструменты (bash, файлы, MCP), локальная среда Alpine.
APK: <ссылка на релиз>, код: <ссылка на репозиторий>.

Сейчас: <N> скачиваний, <N> звёзд, обновления каждую неделю.
Предлагаю: размещение «работает с <ваш провайдер>» в README и в настройках
провайдеров внутри приложения — там, где пользователь выбирает endpoint.
Стоимость: <сумма>/мес, отчёт по переходам раз в месяц.
```

## Где искать

- **awesome-списки** (`awesome-android`, `awesome-ai-agents`, `awesome-mcp-servers`) — после
  попадания туда приходят и звёзды, и первые спонсоры.
- **Awesome-каталоги спонсорства**: `github.com/sponsors` — сообщества, `OpenCollective` —
  можно завести коллекцию и принимать деньги на проект от нескольких людей.
- **Reddit / HN / Lobsters** — пост с результатом, не с рекламой: «сделал агента, который
  правит файлы на телефоне, вот что сломалось по пути».
- **Telegram-каналы про Android и локальные модели** — там же первые подписчики Boosty.
- **Discord-серверы провайдеров моделей** — канал `#showcase`, оттуда пишут dev-rel.

## Правила, чтобы не сломать репутацию

- Не покупать звёзды и не просить «проголосовать» в обмен на что-то — это бан.
- В FUNDING.yml только реально работающие ссылки: битая кнопка Sponsor хуже, чем её отсутствие.
- Обещанное за деньги выполнять: логотип, упоминание, срок размещения.
