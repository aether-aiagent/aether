ИИ-агент на телефон

Aether — открытый ИИ-агент, который живёт прямо на телефоне. Это не чат-обёртка: модель запускает bash, читает и правит файлы, ищет по проекту, поднимает MCP-серверы и работает в локальной среде Alpine. Всё на устройстве, без аккаунта и без бэкенда.

Скачать APK Исходники на GitHub

Что умеет

  • Чат с любой моделью через OpenAI-совместимый API
  • Инструменты: bash, read, write, edit, grep, find, ls — с подтверждением опасных действий
  • Локальная среда Alpine (proot) и интеграция с Termux
  • MCP-серверы, суб-агенты, расширения и навыки
  • Интерфейс на русском, тёмная и светлая тема

Как поставить

Скачай Aether-v2.4.1.apk из Releases и открой файл. Android 8.0 и выше. Обновления ставятся поверх — история чатов сохраняется.

Это бесплатно

Открытый исходный код, лицензия GPL-3.0. Платят только провайдеру модели за токены, если он платный.
