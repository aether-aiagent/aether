# Changelog

## 2.4.1

- Новая палитра: холодный почти чёрный фон с синим акцентом вместо серого
  (#131317 / #23232B, акцент #6E8DFB). Пузырь пользователя — синий,
  кнопки, FAB, выбранный чат и иконки действий — в едином акценте.
- Список чатов переделан в карточки: скругление 22 dp, отступ между строками,
  выбранный чат залит акцентом; поиск всегда на виду отдельной пилюлей.
- Те же цвета перенесены в тему десктопной сборки.

- Список чатов стал читаемым с одного взгляда: у каждого чата своя цветная
  плашка с символом и формой (выводятся из id чата, поэтому не сбиваются при
  переименовании), под названием — превью последнего сообщения, справа время
  для сегодняшних и дата для старых.
- Чаты сгруппированы по дням: «Сегодня», «Вчера», «Раньше».
- Поиск в списке чатов теперь ищет и по тексту сообщений: в строке виден
  найденный фрагмент, совпадение подсвечено.
- Каждый блок кода в ответе получил метку языка и кнопку копирования.
- У ответа появились две новые действия: прочитать вслух (системный TTS,
  повторное нажатие останавливает) и поделиться текстом в другое приложение.
- Агент рисует графики прямо в ответе: ` ```chart ` с JSON (линия, столбцы,
  круговая) превращается в карточку с осями, точками и легендой; карточка
  сворачивается по тапу, а нераспознанный блок остаётся обычным кодом.
- В системный промпт добавлено правило: числовые сравнения и тренды — графиком,
  а не таблицей.
- Новые подстановки в промпте: `{{weekday}}`, `{{device}}`, `{{android}}`,
  `{{locale}}` в дополнение к дате, времени, часовому поясу и timestamp.
- Чаты суб-агентов больше не открываются: убраны полноэкранный просмотрщик
  переписки и переход в сессию агента, остались строка статуса и отчёт
  с результатом.
- Тёмная тема стала чуть светлее (фон #262626, поверхности #343434) — меньше
  контраста с текстом, легче читать длинные ответы.

## 2.4.0

- Новый дизайн в духе ChatGPT/Codex: нейтральная монохромная палитра
  (светлая и тёмная темы), пилюля-композер, мягкие пузыри сообщений,
  зелёный акцент #10A37F, обновлённая типографика.
- Уведомление о владельце при первом запуске: ссылка на Telegram-канал
  [t.me/AetherAIAgent](https://t.me/AetherAIAgent) открывается по тапу,
  кнопка «ОК» закрывает уведомление навсегда.
- Настройки → О приложении: строки «Telegram» и «Исходный код» с прямыми
  ссылками на владельца и публичный репозиторий.
- Агент больше не начинает ответы с рубрик «Коротко:/Важно:/Итог:» —
  стиль ответов ужесточён в системном промпте.
- Debian Desktop 2.4.0: то же уведомление о владельце, тёмная тема в духе
  ChatGPT, ссылки на Telegram и GitHub.
- Релизы теперь версионируются по файлу `VERSION`; CI переиспользует релиз
  и заменяет APK-ассет, подпись и пакет не меняются — обновление ставится
  поверх установленной версии.

## 2.3.0

- Полный ребрендинг проекта: пакет `dev.aetherlab.aether`, автор — Aether Lab,
  все ссылки ведут на официальный репозиторий
  [jcufyr6d5djj-beep/aether](https://github.com/jcufyr6d5djj-beep/aether).
- Автообновление из собственного репозитория: приложение проверяет GitHub
  Releases, скачивает APK и запускает установку (Настройки → О приложении →
  «Проверить обновления», а также фоновая проверка при запуске раз в сутки).
- Интеграция Shizuku: управление виртуальным дисплеем и Agent Mode без root —
  через Shizuku API (метод авторизации «Shizuku» в настройках).
- Сборки nightly публикуются в релизах публичного репозитория и доступны
  прямо из приложения.
- Минификация и сжатие ресурсов: APK стал заметно меньше (≈38 МБ).
- Опросы: кнопка «Написать свой ответ» раскрывает поле ввода внутри карточки,
  ответ отправляется сразу.
- Более контрастная светлая палитра и обновлённая типографика.
- Экранные миссии AI Lab: пресеты, пакеты миссий с параллелизмом, статистика
  и отчёты в Markdown (расширение aether-ai-lab).
