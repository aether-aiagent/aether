# Changelog

## 2.3.0

- Полный ребрендинг проекта: пакет `dev.aetherlab.aether`, автор — Aether Lab,
  все ссылки ведут на официальный репозиторий
  [jcufyr6d5djj-beep/aether](https://github.com/jcufyr6d5djj-beep/aether).
- Автообновление из собственного репозитория: приложение проверяет GitHub
  Releases, скачивает APK и запускает установку (Настройки → О приложении →
  «Проверить обновления», а также фоновая проверка при запуске раз в сутки).
- Интеграция Shizuku: управление виртуальным дисплеем и Agent Mode без root —
  через Shizuku API (метод авторизации «Shizuku» в настройках).
- Сборки nightly публикуются в релизах публичного репозитория и доступны
  прямо из приложения.
- Минификация и сжатие ресурсов: APK стал заметно меньше (≈38 МБ).
- Опросы: кнопка «Написать свой ответ» раскрывает поле ввода внутри карточки,
  ответ отправляется сразу.
- Более контрастная светлая палитра и обновлённая типографика.
- Экранные миссии AI Lab: пресеты, пакеты миссий с параллелизмом, статистика
  и отчёты в Markdown (расширение aether-ai-lab).

## 2.2.0

- CI: автоматическая сборка APK на каждую отправку кода.
